**Skill ID:** `read-team-chat`
**Server:** [RingEX Chat](../servers/ringex-chat.md)

Lets the user browse recent Team Chat conversations or jump straight to a named channel/person, then reads back recent posts, notes, tasks, or events as a formatted stream — with an optional catch-up digest of decisions and open questions on top, and person lookups via the company directory. Read-only, and precise about what this API can't do (no unread counts, read receipts, or full-text search).
