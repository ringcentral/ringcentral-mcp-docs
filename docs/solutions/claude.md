## Installing a plugin manually

Once you have a plugin's `.zip` file, install it directly in Claude:

1. Go to **Settings**.
2. Click **Plugins**.
3. From the pull-down, select **Upload plugin**.
4. Select the plugin `.zip` file.
5. Presto!
